The separate Teacher Ready package is the one intended to be sent to the teacher.

FREE CAMERA + AUDIO (v39)
-------------------------
MathStudio v39 supports Cloudflare Realtime TURN with short-lived credentials.
1. In your Cloudflare account, create a Realtime TURN key.
2. Run "SETUP FREE CAMERA + AUDIO.bat" and paste the TURN Key ID and TURN Key token.
3. Run "TEST CAMERA + AUDIO RELAY.bat". It should say SUCCESS.
4. Restart "START STUDENT WEBSITE.bat" and use the HTTPS URL on every device.

Do not send media_config.bat to anyone or commit it to GitHub. It contains the long-lived TURN key token.
The browser receives only short-lived TURN credentials generated by the local MathStudio server.
