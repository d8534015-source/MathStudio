MathStudio Teacher

Use the verified MathStudio.exe Windows installer. Open MathStudio from the Start menu or desktop shortcut. No VS Code is needed. The Teacher App connects to a separately hosted OWNER server.

On first launch, enter your OWNER server’s HTTPS URL and sign in with your teacher account. Change the server address later in Settings.

Manage public content and translations in MathStudio → Website Management. Students and parents can book lessons, find resources and join classes here.
